Weights written by hand

Every weight is set by hand and shipped in the page. There is no training step and no pretrained model hiding in a download.

02

New text, one token at a time

Every vocabulary token receives a finite score from the network. Softmax turns those scores into probabilities. There are no grammar masks, canned replies, or sentence templates.

03

A model you can understand

This is a small educational model, not a general assistant. It can write longer passages, but its hand-built vocabulary and grammar do not give it world knowledge.

The architecture, the vocabulary, and the limits

A hand-wired recurrent ReLU network. A frozen numeric checkpoint contains token embeddings, recurrent-cell connections, biases, and output weights. The browser’s inference kernel only performs indexed arithmetic, ReLU, and softmax. It does not read token names, parts of speech, or grammar tables.

Syntax, article preferences, subject number, verb–adverb compatibility, and repetition tendencies are encoded in weights and hidden activations. For example, a −24 connection reduces the logit of “together” when the single-subject neuron is active. It is a finite preference, not a prohibition: edit the connection and the model can make that mistake. Temperature changes the distribution; zero selects the largest logit.
The weights are authored by hand, not learned from text. The source includes an offline weight builder for reproducibility. This is an educational model with a small vocabulary and limited representations; it can still produce awkward language and has no general world knowledge.
Its entire vocabulary
Unknown input is mapped to the numeric <unk> embedding. Formatting adds spaces, capitalization, and paragraph breaks; it does not rewrite the model’s word choices. All vocabulary IDs, including special tokens, receive finite logits.
Everything runs in plain JavaScript on the CPU. No server, API key, model download, or internet connection is needed after loading. Continue preserves the model’s hidden state and random generator. Download HTML saves the page with your edited weights; Download weights exports the full numeric checkpoint.

The last eight tokens are shown for reference. Memory is held in 192 activations, not an eight-token window.

A neuron’s activation is multiplied by a learned weight. This contribution is added to the token’s score, called a logit.

Other neurons and a bias contribute too. Softmax converts scores to probabilities. Neurons have no assigned meanings.

r = sigmoid(Wᵣx + Uᵣh + bᵣ)
z = sigmoid(W𝓏x + U𝓏h + b𝓏)
n = tanh(Wₙx + bᵢₙ + r ⊙ (Uₙh + bₕₙ))
h′ = (1 − z) ⊙ n + z ⊙ h
logits = Wₒh′ + bₒ
p = softmax(logits / temperature)
Zero temperature picks the highest score. Packed weights expand to float32. The output limit is not a reliable context length.

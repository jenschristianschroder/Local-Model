A model you can understand

This is a small educational model, not a general assistant. It can write longer passages, but its hand-built vocabulary and grammar do not give it world knowledge.

The architecture, the vocabulary, and the limits

A hand-wired recurrent neural controller with grammar-guided decoding. ReLU gates update a sentence-state vector. Decaying theme memory, a persistent prompt-theme anchor, subject features, and object preferences feed a linear output layer. All numeric matrices are defined in this file; no parameters were learned from training data.

Grammar and article masks select valid token classes. Subject-number memory and verb–adverb rules filter combinations: “hums softly” and “sparkles brightly” are allowed; “together” needs a plural subject in this limited grammar. These rules also apply when you edit weights. Temperature, a 64-token repetition penalty, an optional repeated-trigram guard, and top-p filtering shape the sampling distribution. Only the repeated-trigram guard relaxes if it blocks every option. The same prompt, seed, weights, and settings reproduce the same text. Increasing length does not make this a trained LLM; meaning can drift and sentences can still be odd. Matrix slots, including zeros, are included in the parameter count.
Its entire vocabulary
<bos> marks the beginning and <unk> represents unknown input. Unknown words remain visible in your prompt but do not update the grammar state. Punctuation counts as a token. A full stop begins another sentence; the batch size or Stop button pauses generation.
Everything runs in ordinary JavaScript on the CPU. No WebGPU, server, API key, or internet connection is needed after loading. Generation is incremental, so continuing does not replay the entire document. Download HTML saves a standalone copy, including your current weight edits.

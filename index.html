The architecture, the vocabulary, and the limits

This is a trained GRU language model. Every embedding, recurrent weight, bias, and output connection was optimized from text. The browser runs the frozen network and samples directly from its logits. There are no grammar rules, word blacklists, phrase filters, or sentence repair code.

Weights are stored at eight-bit precision with a scale per matrix row; biases remain float32. They expand to float32 in memory for inference. The complete deployed page stays below 1,000,000 bytes. Edited downloads can grow if you add many overrides.
This model completes short narratives. It is not an instruction-following assistant. It can repeat itself, invent words, lose track of characters, and make grammatical or factual mistakes. More training and a larger vocabulary improve its predictions without guaranteeing fluent long passages.
Its learned token vocabulary
The learned byte-pair tokenizer divides text into reusable word pieces. ␠ marks a word boundary. Pieces can combine into words that are not individual vocabulary entries. Casing, punctuation, and word choices are generated by the model; decoding only joins pieces and restores spaces and paragraph breaks.
No server, API key, model download, or internet connection is needed after loading. Continue preserves the hidden state and random sequence. Download HTML saves this standalone page with edits; Download model exports the checkpoint and any edited output weights.

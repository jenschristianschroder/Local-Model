03

A model you can understand

This is a tiny educational language model, not a general assistant. It only knows its listed vocabulary, sees four tokens, and can make nonsense.

The architecture, the vocabulary, and the limits

A word-level, feed-forward neural language model. Sparse, hand-wired embeddings describe grammar and three small themes. Hidden ReLU units combine those features. The full numeric matrices are constructed in this file and used for every inference.

Temperature 0 uses argmax; otherwise every allowed token participates in softmax sampling. The seed makes sampling repeatable. The model has no attention, memory beyond four tokens, or learned world knowledge. Unknown words map to <unk>. Matrix slots, including zeros, are included in the parameter count.
Its entire vocabulary
<bos> pads the beginning, <unk> represents unknown input, and <end> finishes the continuation. These are control tokens, not printed words. Punctuation is a token too.
Everything runs in ordinary JavaScript on the CPU. No WebGPU, server, API key, or internet connection is needed after loading. Download HTML saves a standalone copy, including your current weight edits.
